# 로컬 감정 일기 MVP

> 구현 화면: `dist/index.html`  
> 기준: 모바일 홈 한 화면 · 현재 브라우저에만 저장

> [목록별 편집 문서 열기](README.md) — 제품 개요, 홈 화면, 기능, 데이터, 메시지, 검수 항목을 각각 수정할 수 있습니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 목적 | 오늘의 감정과 짧은 글을 간편하게 기록하기 |
| 화면 | 모바일 홈 한 화면 |
| 저장 | 현재 브라우저의 `localStorage` |
| 계정 | 회원가입·로그인 없음 |
| 감정 | 행복 😄 · 우울 😔 · 화남 😠 · 기쁨 😊 |
| 기록 수 | 하루 1개, 당일 수정·삭제 가능 |
| 공개 여부 | 외부 전송·공유 없음 |

## 화면 순서

```text
오늘 날짜와 개인정보 안내
        ↓
감정 버튼 4개 (2×2)
        ↓
감정 세기 1~5
        ↓
원인 태그 최대 3개
        ↓
짧은 글 최대 1,000자
        ↓
저장 / 수정 / 삭제
        ↓
이번 주 마음과 최근 기록
```

## 감정 버튼

버튼 안에서 글자와 이모티콘을 나란히 표시한다.

| 코드 | 버튼 |
|---|---|
| `HAPPY` | 행복 😄 |
| `DEPRESSED` | 우울 😔 |
| `ANGRY` | 화남 😠 |
| `JOY` | 기쁨 😊 |

- 모바일에서 누르기 쉽도록 2×2로 배치한다.
- 한 번에 하나만 선택할 수 있다.
- 선택한 버튼은 테두리와 배경색으로 구분한다.
- 색상만 사용하지 않고 글자와 이모티콘을 항상 함께 표시한다.

## 기록 항목

### 필수

- 감정 1개
- 감정 세기 1~5 — 기본값 3

### 선택

- 원인 태그 최대 3개
  - 일·학업, 가족, 대인관계, 연애, 건강
  - 수면, 경제, 미래, 나 자신, 취미·여가
- 짧은 글 최대 1,000자

## 저장 방식

- 서버나 클라우드를 사용하지 않는다.
- 모든 기록은 현재 브라우저의 `localStorage`에만 저장한다.
- 저장 키는 `mood-diary.entries.v1`이다.
- 같은 날짜의 기록은 새로 추가하지 않고 수정한다.
- 브라우저 데이터를 삭제하거나 다른 기기·브라우저를 사용하면 기록을 볼 수 없다.
- 공용 기기에서는 같은 브라우저를 쓰는 다른 사람이 기록을 볼 수 있으므로 주의가 필요하다.

### 기록 데이터

```json
{
  "id": "UUID",
  "date": "YYYY-MM-DD",
  "mood": "HAPPY | DEPRESSED | ANGRY | JOY",
  "intensity": 3,
  "tags": ["가족", "수면"],
  "note": "오늘 남기고 싶은 말",
  "createdAt": "ISO 8601",
  "updatedAt": "ISO 8601"
}
```

## 홈 화면 동작

### 처음 사용할 때

- 빈 기록 폼을 바로 보여준다.
- 감정을 선택하기 전에는 저장 버튼을 비활성화한다.
- 최근 기록 영역에는 `아직 기록이 없어요` 안내를 표시한다.

### 저장할 때

- 감정을 선택하면 저장 버튼이 활성화된다.
- 저장 후 `오늘의 마음을 저장했어요` 메시지를 보여준다.
- 이번 주와 최근 기록을 즉시 갱신한다.

### 오늘 기록이 있을 때

- 기존 기록을 폼에 자동으로 채운다.
- 저장 버튼 문구를 `오늘 기록 수정`으로 바꾼다.
- 삭제 버튼을 표시한다.

### 삭제할 때

- `삭제한 기록은 복구할 수 없습니다` 확인창을 먼저 표시한다.
- 확인 후 오늘 기록만 삭제한다.
- 폼, 이번 주, 최근 기록을 즉시 갱신한다.

## 이번 주와 최근 기록

### 이번 주 마음

- 월요일부터 일요일까지 표시한다.
- 기록한 날에는 선택한 감정 이모티콘을 표시한다.
- 기록하지 않은 날에는 날짜 숫자를 표시한다.
- 오늘은 별도 테두리로 강조한다.

### 최근 기록

- 최신순으로 최대 7개를 표시한다.
- 각 항목에 이모티콘, 날짜, 감정, 세기, 글 미리보기를 넣는다.
- 오늘 기록을 누르면 상단 폼에서 다시 수정할 수 있다.
- 과거 기록은 날짜·감정·세기를 간단히 확인할 수 있다.

## 포함하지 않는 기능

- 회원가입, 로그인, 소셜 로그인
- 서버, 데이터베이스, 기기 간 동기화
- 별도 캘린더·통계·설정 페이지
- 이메일·푸시 알림
- AI 분석, 상담, 의료 진단
- 커뮤니티, 공개 공유, 결제, 광고
- 외부 배포

## 확인 목록

- [ ] 네 감정 버튼이 2×2로 보인다.
- [ ] 각 버튼에서 글자 옆에 이모티콘이 보인다.
- [ ] 감정을 선택해야 저장할 수 있다.
- [ ] 태그는 최대 3개만 선택된다.
- [ ] 하루에 기록이 1개만 저장된다.
- [ ] 오늘 기록을 수정·삭제할 수 있다.
- [ ] 새로고침 후에도 같은 브라우저에서는 기록이 남는다.
- [ ] 다른 브라우저나 기기에서는 기록이 보이지 않는다.
- [ ] 모바일 360px 너비에서 가로 스크롤이 생기지 않는다.
- [ ] 키보드로 모든 입력과 버튼을 사용할 수 있다.
