## 수정 방법

1. 위 표에서 수정할 문서를 선택합니다.
2. 문서의 `확정 내용`을 고칩니다.
3. 결정되지 않은 내용은 `수정 메모`의 체크박스 아래에 적습니다.
4. 결정이 끝나면 체크박스를 완료 상태인 `[x]`로 바꿉니다.
5. 기능이 바뀌면 [검수 체크리스트](sections/06-acceptance-checklist.md)도 함께 수정합니다.

## 현재 핵심 결정

- [x] 모바일 홈 한 화면으로 구성
- [x] 회원가입과 로그인 없음
- [x] 현재 브라우저에만 기록 저장
- [x] 감정은 `행복 😄`, `우울 😔`, `화남 😠`, `기쁨 😊`
- [x] 하루 한 건 작성, 당일 수정·삭제 가능
- [x] 서버·클라우드·외부 배포 제외
