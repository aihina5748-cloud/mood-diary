# 언어치료 대화 선택 서비스 기획안 초안

> 상태: 1단계 서비스 기획 중 — 개발 전 검토용

## 1. 서비스 개요

언어지연 또는 장애가 있는 학령기 전 아동이 언어치료 시간에 사용할 수 있는 대화 선택형 웹서비스다. 아동은 또래 캐릭터가 등장하는 놀이 상황을 사진형 장면과 말풍선으로 보고, 5개의 짧은 답변 중 하나를 선택한다. 선택 결과에 따라 상대 캐릭터의 감정과 행동이 달라지며, 대화를 다시 회복하는 과정을 연습한다.

## 2. 사용자

### 주 사용자

- 언어지연 또는 장애가 있는 학령기 전 아동
- 글을 읽거나 그림·짧은 문장을 보고 선택할 수 있는 아동

### 보조 사용자

- 언어치료사
- 치료 상황에 따라 아동의 선택과 대화를 함께 관찰하는 보호자

성인은 정답을 대신 고르는 사람이 아니라 활동을 시작하고 아동의 반응을 관찰하는 역할을 맡는다.

## 3. 서비스 목표

- 놀이 중 자주 생기는 또래 대화 상황을 안전하게 경험한다.
- 부탁, 거절, 차례 지키기, 사과, 감정 표현, 도움 요청과 같은 표현을 연습한다.
- 자신의 말이 상대방의 기분과 행동에 어떤 영향을 줄 수 있는지 장면으로 확인한다.
- 오답 이후에도 다시 말해보고 관계를 회복하는 경험을 제공한다.
- 에피소드가 끝난 뒤 자신의 현재 감정과 느낀 점을 표현한다.

## 4. 핵심 등장인물

기존에 제작한 캐릭터 이미지를 그대로 사용한다.

- 황시완: 서비스의 아동 사용자 캐릭터
- 박건후: 고집과 욕심이 강하지만 다정할 때는 엉뚱하게 잘 노는 남자아이
- 김시아: 친절하고 누나처럼 상대의 실수를 잘 받아주는 여자아이

사용 이미지:

## 5. 기본 이용 흐름

1. 친구 캐릭터가 그려진 문을 선택한다.
2. 문이 열리고 놀이 에피소드가 시작된다.
3. 상황 사진과 친구의 말풍선이 표시된다.
4. 아동이 5개의 짧은 답변 중 하나를 선택한다.
5. 선택 직후 같은 장면에서 상대 친구의 표정, 자세, 말풍선이 바뀌며 결과를 재연한다.
6. 적절한 답변이면 자연스러운 긍정 반응 후 다음 대화 차례로 넘어간다.
7. 적절하지 않은 답변이면 상황에 맞는 부정적 반응이 나타난다.
8. `이렇게 말하면 어떨까?` 도움 카드와 새로운 답변 선택지를 제공한다.
9. 아동이 다시 선택하여 대화를 회복한다.
10. 한 에피소드에서 최소 3번 이상 말을 주고받는다.
11. 에피소드가 끝나면 감정·기분·느낀 점을 묻는다.

## 6. 대화 에피소드 구조

### 필수 구성

- 에피소드 하나당 최소 3개의 대화 차례
- 각 차례마다 상황 사진 1개와 친구 말풍선 1개
- 아동 답변 선택지 5개
- 답변은 학령기 전 아동이 실제로 사용할 법한 짧은 문장으로 작성
- 캐릭터 성격에 따라 말투와 반응을 다르게 작성
- 적절한 답변이 하나 이상 존재할 수 있음

### 적절한 답변을 선택했을 때

- 상대 친구가 이해, 수락, 협력 또는 차분한 거절로 반응한다.
- 아동의 선택이 상대에게 어떤 도움을 주었는지 짧게 보여준다.
- 다음 대화 차례로 이동한다.

### 적절하지 않은 답변을 선택했을 때

상황과 캐릭터 성격에 따라 다음 반응 중 하나를 장면으로 보여준다.

- 짜증을 내며 말투가 강해짐
- 화를 내거나 놀이를 중단함
- 속상해서 울음
- 대화를 멈추고 자리를 피함
- 가지고 있던 장난감을 내려놓거나 등을 돌림

이 반응을 정답을 틀린 것에 대한 벌처럼 사용하지 않는다. 실제 아동의 반응은 개인마다 다르므로, 화면에는 `이 말을 들은 친구는 이렇게 느낄 수도 있어`라는 의미로 제시한다.

부정적 반응 뒤에는 반드시 다음 회복 단계를 제공한다.

1. 친구의 현재 감정을 짧은 말과 표정으로 보여준다.
2. `이렇게 말하면 어떨까?` 도움 카드를 표시한다.
3. 사과, 설명, 다시 부탁하기, 잠시 쉬기 등의 대안 표현을 제안한다.
4. 아동이 답변을 다시 선택할 수 있게 한다.
5. 회복 답변을 선택하면 친구가 진정하거나 대화를 다시 시작한다.

## 7. 에피소드 예시

### 블록을 같이 쓰는 상황 — 박건후

1차 대화:

- 건후: `시완아, 그 노란 블록도 나 줘! 내가 큰 탑 만들 거야.`
- 시완이의 답변 5개 중 하나 선택

오답 예시:

- 시완: `안 돼! 다 내 거야.`
- 건후: 얼굴을 찡그리고 블록을 잡으며 `나도 쓰고 싶단 말이야!`라고 말함
- 도움 카드: `이렇게 말하면 어떨까? — 나도 두 개 필요해. 하나씩 나눠 쓰자.`
- 아동이 회복 답변을 다시 선택

2차 대화:

- 건후: `그럼 노란 블록 하나씩 쓰자. 탑은 어디에 만들까?`
- 시완이가 장소를 제안하거나 건후에게 물어보는 답변 선택

3차 대화:

- 탑이 무너진 상황에서 놀리기, 도와주기, 원인을 말하기 등의 답변 선택
- 마지막에는 둘이 다시 탑을 만드는 장면으로 마무리

## 8. 에피소드 종료 후 감정 표현

에피소드가 끝나면 한 화면에 한 질문씩 보여준다.

1. `지금 기분은 어때?`
   - 기뻐요
   - 편안해요
   - 속상해요
   - 화나요
   - 잘 모르겠어요
2. `친구가 화냈을 때 어떤 느낌이 들었어?`
3. `다시 말한다면 어떻게 말하고 싶어?`

아동은 그림 감정 카드나 짧은 문장을 선택할 수 있다. 마지막 질문에는 `이렇게 말하면 어떨까?` 예시 문장을 함께 제공하되, 아동이 먼저 생각할 시간을 준 뒤 열어볼 수 있게 한다.

## 9. 화면 구조

1. 시작 화면
   - 서비스 이름
   - 시작 버튼
2. 친구 선택 화면
   - 건후의 문
   - 시아의 문
3. 에피소드 소개 화면
   - 오늘의 놀이 장소와 목표
4. 상황 대화 화면
   - 상황 사진
   - 친구 캐릭터와 말풍선
   - 답변 선택지 5개
5. 선택 결과 재연 화면
   - 선택한 말
   - 친구의 표정·행동·말풍선 변화
6. 회복 대화 화면
   - `이렇게 말하면 어떨까?`
   - 다시 고를 수 있는 답변
7. 감정 돌아보기 화면
   - 감정 그림 카드
   - 느낀 점 질문
8. 완료 화면

## 10. 디자인 원칙

- 모바일 세로 화면을 우선한다.
- 한 화면에는 하나의 상황과 하나의 질문만 보여준다.
- 본문 글자는 최소 16px 이상, 주요 대사는 더 크게 표시한다.
- 답변 버튼은 손가락으로 쉽게 누를 수 있도록 크게 만든다.
- 선택지마다 번호와 짧은 문장을 함께 표시한다.
- 갑작스러운 큰 소리, 빠른 깜빡임, 과도한 흔들림을 사용하지 않는다.
- 부정적 반응은 짧고 명확하게 표현하고 오래 반복하지 않는다.
- `틀렸어`라는 표현보다 친구의 감정과 다음에 할 수 있는 말을 알려준다.
- 진단명이나 장애 정보는 아동 화면에 표시하지 않는다.

## 11. 초기 개발 범위

- 기존 시완·건후·시아 캐릭터 재사용
- 건후 에피소드 1개
- 시아 에피소드 1개
- 에피소드별 최소 3회 대화
- 매 대화마다 답변 5개
- 정답 진행, 오답 반응, 도움 카드, 재선택 기능
- 에피소드 종료 후 감정 질문 3개
- 모바일 로컬 웹 실행

## 12. 기획 단계에서 추가로 결정할 사항

- 최종 서비스 이름
- 글을 읽기 어려운 아동을 위한 음성 읽기 기능 포함 여부
- 치료사가 에피소드와 답변을 직접 추가하는 기능 포함 여부
- 감정 답변을 기기에 저장할지 여부
- 부정적 반응의 표현 강도와 허용 범위
- 각 에피소드에서 재시도할 수 있는 최대 횟수
