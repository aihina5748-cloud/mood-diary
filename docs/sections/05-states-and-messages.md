# 05. 상태와 메시지

[← 문서 목록으로](../README.md)

## 화면 상태

| 상태 | 표시 내용 | 사용자 행동 |
|---|---|---|
| 첫 방문 | 빈 입력 폼, 최근 기록 빈 상태 | 첫 기록 작성 |
| 감정 미선택 | 저장 버튼 비활성화 | 감정 선택 |
| 태그 3개 선택 | 추가 태그 선택 거절 | 기존 태그 해제 후 선택 |
| 오늘 기록 존재 | 기존 값, 수정·삭제 버튼 | 수정 또는 삭제 |
| 저장 성공 | 목록 즉시 갱신, 성공 토스트 | 기록 확인 |
| 삭제 확인 | 복구 불가 안내창 | 취소 또는 삭제 |
| 데이터 없음 | `아직 기록이 없어요` | 오늘 기록 작성 |
| 저장 오류 | 입력 유지, 오류 토스트 | 다시 시도 |

## 사용자 메시지

| 상황 | 문구 |
|---|---|
| 개인정보 안내 | `기록은 이 브라우저에만 저장돼요` |
| 새 기록 성공 | `오늘의 마음을 저장했어요.` |
| 수정 성공 | `오늘의 기록을 수정했어요.` |
| 삭제 성공 | `오늘의 기록을 삭제했어요.` |
| 태그 초과 | `원인은 최대 3개까지 선택할 수 있어요.` |
| 빈 목록 | `아직 기록이 없어요` |
| 글 입력 안내 | `짧게 적어도 좋아요.` |
