# 01. 제품 개요

[← 문서 목록으로](../README.md)

## 확정 내용

### 한 줄 설명

모바일 브라우저에서 오늘의 감정과 짧은 글을 기록하고, 같은 브라우저에서 최근 기록을 돌아보는 개인용 감정 일기입니다.

### 사용자

- 간단하게 감정을 기록하고 싶은 일반 사용자
- 회원가입 없이 바로 사용하고 싶은 사용자
- 개인 기록을 외부 서버에 보내고 싶지 않은 사용자

### 목표

- [x] 처음 접속한 사용자가 바로 기록할 수 있게 한다.
- [x] 모바일에서 한 손으로 감정 선택과 저장을 완료하게 한다.
- [x] 기록을 현재 브라우저에만 보관한다.
- [x] 오늘 기록을 같은 화면에서 수정·삭제할 수 있게 한다.

### 제품 원칙

- **간단하게:** 불필요한 화면 이동과 입력을 줄입니다.
- **비공개로:** 기록을 외부 서버에 전송하지 않습니다.
- **명확하게:** 글자와 이모티콘을 함께 사용합니다.
- **부담 없이:** 감정과 세기만으로도 저장할 수 있습니다.

### 포함하지 않는 기능

- 회원가입, 로그인, 소셜 로그인
- 서버, 데이터베이스, 클라우드 동기화
- 커뮤니티, 공개 공유, 결제, 광고
- 이메일·푸시 알림
- AI 분석, 상담, 의료 진단
- 별도 캘린더·통계·설정 화면
- 외부 배포
