# 03. 기록 기능

[← 문서 목록으로](../README.md)

## 확정 내용

### 입력 항목

| 항목 | 필수 | 규칙 |
|---|---:|---|
| 감정 | 예 | 네 감정 중 하나 |
| 감정 세기 | 예 | 1~5, 기본값 3 |
| 원인 태그 | 아니요 | 최대 3개 |
| 짧은 글 | 아니요 | 최대 1,000자 |

### 원인 태그

- 일·학업
- 가족
- 대인관계
- 연애
- 건강
- 수면
- 경제
- 미래
- 나 자신
- 취미·여가

### 작성

1. 감정을 선택합니다.
2. 감정 세기를 조절합니다.
3. 필요한 경우 원인과 글을 입력합니다.
4. `오늘 기록 저장`을 누릅니다.
5. 저장 후 이번 주와 최근 기록을 즉시 갱신합니다.

### 수정

- 오늘 기록이 있으면 폼에 기존 값을 자동으로 채웁니다.
- 버튼 문구를 `오늘 기록 수정`으로 바꿉니다.
- 다시 저장하면 새 기록을 만들지 않고 기존 기록을 갱신합니다.

### 삭제

- 오늘 기록이 있을 때만 삭제 버튼을 표시합니다.
- 삭제 전 복구할 수 없다는 확인창을 표시합니다.
- 확인 후 오늘 기록만 제거합니다.

### 최근 기록

- 최신순으로 최대 7개를 표시합니다.
- 이모티콘, 날짜, 감정, 세기, 글 미리보기를 보여줍니다.
- 오늘 기록을 누르면 입력 폼으로 불러옵니다.
- 과거 기록은 간단히 조회할 수 있고 MVP에서는 수정하지 않습니다.
