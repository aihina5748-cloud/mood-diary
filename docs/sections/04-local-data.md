# 04. 데이터와 개인정보

[← 문서 목록으로](../README.md)

## 확정 내용

### 저장 정책

- 저장 위치: 현재 브라우저의 `localStorage`
- 저장 키: `mood-diary.entries.v1`
- 서버 전송: 없음
- 계정 식별자: 없음
- 외부 분석 도구: 없음
- 날짜 기준: 사용자 기기의 현지 날짜
- 기록 수: 날짜별 한 건

### 데이터 구조

```json
{
  "id": "UUID",
  "date": "YYYY-MM-DD",
  "mood": "HAPPY | DEPRESSED | ANGRY | JOY",
  "intensity": 3,
  "tags": ["가족", "수면"],
  "note": "오늘 남기고 싶은 말",
  "createdAt": "ISO 8601",
  "updatedAt": "ISO 8601"
}
```

### 사용자 안내

- 기록은 현재 브라우저 안에만 저장됩니다.
- 브라우저 데이터를 삭제하면 기록도 사라질 수 있습니다.
- 다른 기기나 다른 브라우저에서는 기존 기록을 볼 수 없습니다.
- 공용 기기에서는 같은 브라우저 사용자에게 기록이 보일 수 있습니다.

### 안전 처리

- 글은 일반 텍스트로 저장합니다.
- 화면에 표시할 때 HTML 특수 문자를 이스케이프합니다.
- 손상된 저장 데이터는 빈 기록 목록으로 안전하게 처리합니다.
