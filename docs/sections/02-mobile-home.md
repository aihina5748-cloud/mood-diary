# 02. 모바일 홈 화면

[← 문서 목록으로](../README.md)

## 확정 내용

### 화면 순서

1. 오늘 날짜와 개인정보 안내
2. 감정 버튼 4개
3. 감정 세기 1~5
4. 원인 태그 최대 3개
5. 짧은 글 최대 1,000자
6. 저장·수정·삭제 버튼
7. 이번 주 마음
8. 최근 기록

### 감정 버튼

| 코드 | 화면 표시 | 배치 |
|---|---|---|
| `HAPPY` | 행복 😄 | 첫째 줄 왼쪽 |
| `DEPRESSED` | 우울 😔 | 첫째 줄 오른쪽 |
| `ANGRY` | 화남 😠 | 둘째 줄 왼쪽 |
| `JOY` | 기쁨 😊 | 둘째 줄 오른쪽 |

- [x] 네 버튼을 2×2로 배치
- [x] 글자 옆에 이모티콘 표시
- [x] 한 번에 한 감정만 선택
- [x] 선택한 버튼은 테두리와 배경색으로 강조
- [x] 색상만으로 상태를 구분하지 않음

### 모바일 기준

- 최대 화면 너비: 430px
- 최소 확인 너비: 360px
- 주요 버튼 높이: 44px 이상
- 데스크톱에서는 모바일 화면을 가운데 배치
- 가로 스크롤 없음

## 수정 메모

- [ ] 전체 색상과 서비스 분위기 최종 확인
- [ ] 감정 버튼 순서 변경 여부 검토
- [ ] 이번 주 영역을 홈에 계속 둘지 검토
